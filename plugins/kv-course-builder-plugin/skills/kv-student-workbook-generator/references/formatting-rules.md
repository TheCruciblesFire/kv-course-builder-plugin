# Workbook Formatting Rules

## Student-Facing Only

Exclude:

- leader notes
- facilitator instructions
- answer keys
- teacher scripts
- timing notes
- behind-the-scenes source comments

If leader guidance is requested, recommend a separate leader-guide asset rather than mixing it into the student workbook.

## Response Spaces

Use clear response cues:

```markdown
Your response:
__________________________________________________
__________________________________________________
```

or:

```markdown
Notes:
- 
- 
- 
```

For print/digital flexibility, avoid excessive blank lines. Use enough space to signal the expected response length.

## Tables

When a response space is already inside a table cell, do not add long blank response lines inside the table. The empty cell or short cue is sufficient.

## Scripture Handling

- Label exact quotations with the translation when known.
- Do not place quotation marks around summaries or paraphrases.
- Use specific references.
- For distribution-ready resources quoting CSB, ensure attribution requirements are handled through `kv-scripture-formatting-check` when needed.
- Do not invent Blue Letter Bible URLs; use placeholders if exact links are uncertain.

## Print Usability

Prefer:

- short paragraphs
- clear headings
- numbered questions
- moderate spacing
- minimal nested bullets
- no cramped mega-tables unless the workbook activity requires them

Avoid:

- dense blocks of text
- too many decorative dividers
- excessive response lines
- mixing multiple asset types into one document
