# Installation Notes

1. Upload `skill.zip` through the ChatGPT Skills interface.
2. Confirm the installed Skill name is `kv-student-workbook-generator`.
3. Confirm the display name is `KV Student Workbook Generator`.
4. Run the included test prompts before treating the Skill as production-ready.
5. Validate that it produces a student-facing workbook only, not a leader guide, slide deck, devotional, course, or interactive exercise.
6. Confirm coordination with:
   - `kv-source-transparency-check`
   - `kv-passage-faithfulness-check`
   - `kv-multi-asset-throttle`
   - `kv-scripture-formatting-check`
   - `kv-interaction-evaluator`
7. Do not build additional KV Skills until this Skill passes its source-preservation, student-facing, formatting, and boundary tests.
