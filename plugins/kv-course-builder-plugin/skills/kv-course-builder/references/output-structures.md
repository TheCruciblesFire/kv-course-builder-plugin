# Course Builder Output Structures

## Course Build Sheet
1. Course Title
2. Course Promise
3. Target Learner Description
4. Starting Point and Desired Transformation
5. Overall Learning Outcomes
6. Recommended Number of Modules
7. Module-by-Module Course Map
8. Final Course Response or Capstone Moment
9. Cohort or Facilitation Note
10. Downstream Asset Notes
11. Build / Handoff Notes

## Module Map
- Module title
- Central question
- Module objective
- Key Scripture/source
- Module summary
- Lesson count
- Lesson sequence
- Reflection/application focus
- Sequence rationale

## Lesson Draft
1. Lesson Title
2. Lesson Objective
3. Learner-Facing Intro
4. Learn
5. Guided Practice
6. Optional Cohort Discussion Prompt
7. On Your Own

## Course Revision
- Preserve approved architecture unless the requested revision requires upstream change.
- Identify the narrowest layer needing revision.
- State downstream consequences only when material.
