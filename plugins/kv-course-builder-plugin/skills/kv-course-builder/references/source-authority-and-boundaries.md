# Source Authority and Boundaries

## Authority
1. Scripture in context.
2. Approved study handoff or controlling source material.
3. User-approved course framework, audience, scope, and project decisions.
4. Active Course Builder references.
5. Validated supporting Skill outputs.
6. External sources only when requested or required.

Do not silently blend conflicts. Do not treat a newer timestamp alone as approval.
Do not promote project-specific courses into global plugin knowledge.

## Core versus supporting Skills
Course Builder core owns architecture, sequencing, learning outcomes, teaching flow, lesson drafts, reflection/application strategy, and course integrity.

Supporting Skills own formal audits, source transparency, Scripture-formatting QA, interaction evaluation, multi-asset throttling, study-to-course conversion, and learner-resource transformations.

## Upstream boundary
Fresh exegesis, lexical study, historical/background research, interpretive-option comparison, and source inventory remain upstream in Study Engine.

## Downstream boundary
Finished workbooks, facilitator guides, handouts, print packets, slides, media, platform packages, publishing bundles, and upload-ready assets remain downstream.
