# Course Design Standard

Derived from the approved Course Builder design philosophy.

## Core commitments
- Formation, not information accumulation.
- Adult learner respect.
- Visible progression at course, module, and lesson level.
- Scripture/text-driven clarity for biblical courses.
- Focused practical response.
- Sustainable cognitive and assignment load.

## Preferred course rhythm
1. Clarify the teaching burden.
2. Define the learner starting point.
3. Define the desired transformation.
4. Build the course spine.
5. Sequence modules.
6. Sequence lessons with one main movement each.
7. Design Guided Practice and personal follow-through.
8. Stabilize course content before downstream assets.

## Preferred lesson rhythm
1. Lesson Title
2. Lesson Objective
3. Learner-Facing Intro
4. Learn
5. Guided Practice
6. Optional Cohort Discussion Prompt
7. On Your Own

Guided Practice should normally contain no more than 2-3 distinct learner actions.
On Your Own should normally contain one focused personal practice or response.

## Adult-learning checks
- Is relevance clear?
- Is progression visible?
- Does the learner do something meaningful?
- Is cognitive load realistic?
- Is the response concentrated rather than fragmented?
- Does each activity serve the objective?
- Is the course suitable for real ministry use?
