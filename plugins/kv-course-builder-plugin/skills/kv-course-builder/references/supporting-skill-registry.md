# Supporting Skill Registry

- `kv-study-to-course-handoff`: converts approved study material into a bounded Course Builder handoff.
- `kv-passage-faithfulness-check`: checks course claims, frameworks, outcomes, and applications for textual overreach.
- `kv-source-transparency-check`: audits source categories and disclosure.
- `kv-interaction-evaluator`: determines whether learner content should become an interaction and recommends the lightest effective mode.
- `kv-scripture-formatting-check`: audits quotations, references, translations, CSB attribution, and BLB link handling.
- `kv-multi-asset-throttle`: controls requests for three or more distinct outputs.
- `kv-student-workbook-generator`: converts completed course content into a student-facing workbook.
- `kv-leader-guide-generator`: converts completed course content into a leader/facilitator guide.
- `kv-one-page-handout-generator`: converts completed teaching into a concise learner handout.
- `kv-print-ready-packet-polish`: performs final print/PDF packet cleanup after content exists.

`kv-study-engine`, `kv-sermon-builder`, and `kv-devotion-builder` are separate domain owners, not bundled supporting procedures for Course Builder core work.
